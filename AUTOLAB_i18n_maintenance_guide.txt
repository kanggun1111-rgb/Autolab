
AUTOLAB WEBSITE i18n & CONTENT MAINTENANCE GUIDE
===============================================

이 문서는 Auto_Lab 웹사이트를 처음 인수받은 사람이
코드를 깊게 몰라도 콘텐츠 수정 및 유지보수를 할 수 있도록 작성된 가이드입니다.

------------------------------------------------
1. 전체 구조 개요
------------------------------------------------

이 웹사이트는 "정적 사이트 + JSON 기반 콘텐츠 관리" 구조입니다.

- HTML : 레이아웃(뼈대)만 담당
- CSS  : 디자인
- JS   : 데이터(JSON)를 HTML에 주입
- JSON : 모든 문구/콘텐츠의 실제 내용

⚠️ 원칙:
HTML에는 언어(한글/영어)를 직접 쓰지 않습니다.
모든 텍스트는 JSON에서 관리합니다.

------------------------------------------------
2. i18n(다국어) 시스템 개념
------------------------------------------------

HTML:
<p data-i18n="home.hero.subtitle"></p>

JSON:
{
  "home.hero.subtitle": {
    "ko": "한글 문구",
    "en": "English text"
  }
}

JS:
- data-i18n 값을 key로 사용
- 현재 언어(ko/en)에 맞는 문구를 JSON에서 찾아
- HTML에 자동으로 삽입

즉,
data-i18n = 주소
JSON        = 번역 사전
JS          = 연결 담당

------------------------------------------------
3. 네이밍 규칙 (가장 중요)
------------------------------------------------

[기본 형식]
페이지.섹션.역할

예시:
home.hero.title
home.hero.subtitle
home.why.points.aero
sponsors.hero.subtitle
vehicles.detail.spec.power

규칙:
- 소문자만 사용
- 단어 구분은 점(.) 사용
- 의미 단위로 나눌 것
- 한글 사용 ❌

------------------------------------------------
4. 페이지별 Prefix 규칙
------------------------------------------------

메인 페이지      : home.*
팀 페이지        : team.*
차량 페이지      : vehicles.*
뉴스 페이지      : news.*
스폰서 페이지    : sponsors.*
공통 에러/라벨   : common.*

예시:
news.error.not_found
common.error.load_failed

------------------------------------------------
5. HTML 작성 규칙
------------------------------------------------

✅ 올바른 예시:
<p data-i18n="team.intro.desc"></p>

❌ 잘못된 예시:
<p data-i18n="team.intro.desc">팀 소개 문구</p>

이유:
- 기준 문구는 JSON
- HTML은 항상 비워두는 것이 원칙

------------------------------------------------
6. <br> 이 필요한 문구 (주소 등)
------------------------------------------------

HTML:
<p data-i18n-html="contact.location.address"></p>

JSON:
"contact.location.address": {
  "ko": "주소 첫 줄<br>주소 두 번째 줄",
  "en": "Address line 1<br>Address line 2"
}

⚠️ data-i18n-html은 innerHTML로 처리됨

------------------------------------------------
7. JSON 수정 방법
------------------------------------------------

파일 위치:
main/site.json

구조:
{
  "i18n": {
    "ko": {
      "key": "한글"
    },
    "en": {
      "key": "English"
    }
  }
}

새 문구 추가 절차:
1. HTML에 data-i18n 키 추가
2. site.json의 ko/en에 동일한 키 추가
3. 저장 후 새로고침

------------------------------------------------
8. 버튼 / 헤더 처리 규칙
------------------------------------------------

- 네비게이션(nav)
- 버튼(a, button)
- 헤더(h1~h6)

위 요소들은 의도적으로 i18n에서 제외됨.
(영문 고정 디자인 정책)

------------------------------------------------
9. 자주 발생하는 문제
------------------------------------------------

Q. 언어 전환이 안 된다
A. data-i18n 키가 없거나 site.json에 키가 없음

Q. 빈 텍스트가 나온다
A. JSON에 해당 언어 값이 없음

Q. 줄바꿈이 사라진다
A. data-i18n 대신 data-i18n-html 사용해야 함

------------------------------------------------
10. 유지보수 체크리스트
------------------------------------------------

□ HTML에 하드코딩된 한글이 있는가?
□ data-i18n 키 네이밍이 규칙을 지켰는가?
□ site.json의 ko/en 둘 다 채워졌는가?
□ <br> 포함 문구는 data-i18n-html인가?

------------------------------------------------
11. 권장 작업 흐름 요약
------------------------------------------------

1. HTML에 data-i18n 키만 작성
2. site.json에서 문구 관리
3. 디자인은 CSS에서만 수정
4. JS는 웬만하면 건드리지 않기
