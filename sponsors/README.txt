Autolab Sponsors Page Pack

Files (place into Autolab/sponsors/):
- sponsors.html
- sponsorsstyle.css
- sponsors.js
- sponsors.json

Install:
1) Copy files into Autolab/sponsors/
2) Paste main navbar (<header>...</header>) into sponsors.html where indicated
3) Add logos into Autolab/sponsors/images/
4) Edit /sponsors/sponsors.json only (tiers/items)

Tier names (fixed):
- Title
- Gold
- Silver
- Support

Logo cropping fix:
- Uses object-fit:contain + max-height so logos never get cut.
